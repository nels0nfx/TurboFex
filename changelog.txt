TurboFex v0.4.0 - link previews and 30 new commands
NEW
- Link previews: every message with a link now shows the preview card (picture, title, description). The WhatsApp library only makes them when an optional package is installed, which is why none ever showed. The bot makes them itself and only reads public web addresses (linkpreview on / off / test)
- Security: ratelimit, anticall, privacy, antipromote, antidemote, antimedia, slowmode
- Community (new category): rules, setrules, report, rank, top, giveaway, birthday, setbirthday, feedback
- Lookup (new category): weather, define, wiki, currency, translate
- Media and tools: dl (video download), take (change a sticker's pack and author), attp (text sticker), setgpp (group picture), note, todo
- Owner: stats (usage, busiest groups, last errors), broadcast (all groups, paced, with confirmation), linkpreview
CHANGED
- Downloads (play, dl) refuse private and internal addresses
- Menu: new categories Security, Community and Lookup (alphabetical like the others)
- promote and demote respect antipromote / antidemote

TurboFex v0.3.0 - production release
NEW
- Login backup: a copy of the WhatsApp login is made daily (last 3 kept, never sent over WhatsApp) and restored automatically if the login file gets damaged. Commands: loginbackup, sessionclean. Old encryption files of chats silent for 90+ days are cleaned monthly
- Safer updates: a downloaded update is checked before any file is replaced (every file must compile, required files must exist). A broken zip is rejected and nothing changes
- Sticker credit: the stickers the bot makes show a pack name and author. Change it with stickerpack
- Reactions: new "smart" mode (cmdreact smart): only slow commands get a reaction. Fewer messages, less ban risk
- Status safety: daily like limit (statuslimit, default 200) and a pause between likes. Views are never limited
- Tests and CI: 61 automated tests run on every push (npm test), a README for GitHub
CHANGED
- Every command reply now uses WhatsApp formatting (bold titles and labels, bullets, commands and examples in monospace). Content commands (jokes, translations, text tools) keep their content untouched
- Menu categories are listed alphabetically
- statusinfo rewritten and fixed
FIXED
- "flip" was defined by two commands (coin and picture flip) and "mute" by two (group close and video mute): one silently replaced the other. The coin command keeps "coin", the group command keeps "close"
- Two login backups in the same day no longer overwrite each other
- Status likes no longer pile up when the bot restarts
- A few command descriptions and aliases cleaned up

TurboFex v0.1.9 - view-once, status, server protection
FIXED
- View-once: the bot now tries harder to download the media (more request shapes) and tells you when WhatsApp refuses to give the file to this device, instead of staying silent. Optional BOT_BROWSER=android (link again) lets the bot receive them

TurboFex v0.1.8 - fixes for slowness, "Waiting for this message", status, watchers and play
FIXED
- "Waiting for this message": the bot now keeps what it sent so WhatsApp can ask for it again (it was missing). The timing overrides added in v0.1.7 that could make connections and sends fail were removed
- Slow sending (group replies took ~27 s): encryption keys are now kept in memory instead of being read from the disk every time
- Missed commands: a command never waits behind another command (or a long job) in the same chat any more. Only game answers stay in order
- Anti-delete: the copy is now a REPLY to the original message in its chat, names who sent it AND who deleted it (the admin or the sender), and also catches deletions that WhatsApp reports as updates. Never shown twice
- Anti-edit: now also catches edits that WhatsApp reports as message updates or as wrapped messages, and replies to the original
- Auto view-once: when WhatsApp refuses the download you are told why instead of silence
- Status auto view/like/save: counters and a fallback way of marking a status as seen; the status owner is added to the like list in both id forms. !statusinfo shows what arrived and any problem
- .block: phone numbers behind hidden ids are learned from messages, contacts and your groups (kept on disk), so blocking in a private chat now has the number. More request shapes are tried and the reply lists exactly what was tried
- play: a song name now sends REAL AUDIO when it is on Audius (free music by independent artists); otherwise it shows YouTube links and says why
- Auto repair of "Bad MAC" runs at most every 3 hours (each repair makes the next sends slower while WhatsApp sets up new keys)
